## 2. Prioritized Technical Risk Register

| Risk ID | Subsystem | Description of Failure Mode | Likelihood | Impact | Prevention & Recovery Strategy |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **R-01** | **Host Memory (`0 B` Swap)** | Compiling ~8,963 generated C++ functions in a single file or with high `-j` parallelism exceeds ~9.8 GiB available RAM and triggers the Linux kernel OOM killer (`SIGKILL`, exit code `137`). | **High** (if unmitigated) | **Critical** | Use `single_file_output = false` with 32–64 unity batch `.cpp` files (~140–280 functions/file), `ninja -j2`, and `-O1` or `-O2 -fno-var-tracking-assignments` on generated code. |
| **R-02** | **Root Disk (`/`, `1.1 GiB` Free)** | Writing `/tmp/cc*` compiler temporaries, CMake FetchContent downloads, or ISO extracts to `/` fills `/dev/sdb3` (99% full) and aborts the build with `No space left on device`. | **High** (if unmitigated) | **Critical** | Export `TMPDIR=/mnt/6421-8598/building/RozuRecomp/out/tmp` in every shell session and keep all build/extract directories under `/mnt/6421-8598/building/RozuRecomp/out/`. |
| **R-03** | **`.vutext` Mis-Disassembly** | `SLUS_214.48` marks `[1406] .vutext` (`0x00291230`–`0x002953B0`) with `SHF_EXECINSTR`. If `ps2xRecomp` treats `.vutext` as R5900 code, it emits invalid instructions/jumps. | **Certain** (without M02 patch) | **High** | Patch `ElfParser::isExecutableSection()` in M02 to exclude `.vutext` and `.DVP.overlay*`, and assert 0 functions in `[0x00291230, 0x002953B0)` in `config/slus_21448.toml`. |
| **R-04** | **`libpad2` / `BedPad` Unresponsive Input** | `BedPad` (`0x00101AEC`) calls `sceDbcInit` + `scePad2CreateSocket` + `scePad2Read`. Without `libpad2` overrides, `dbcman.cpp` stubs out the RPCs and the game never receives controller input. | **Certain** (without M08 patch) | **High** | Implement `sceDbc*`, `scePad2*`, and `sceVib*` HLE stubs in `Pad.cpp` and bind their exact `SLUS_214.48` addresses (`0x0026DF00`–`0x00270A00`) via `ps2_game_overrides`. |
| **R-05** | **`MagSystem::waitVSync` Deadlock** | `MagSystem::waitVSync` (`0x00118754`) spins on `while (sceDmaSync(m_dma, 1, 0))` and then blocks on `WaitSema(m_v_sema)` signaled by `vsyncHandler` (`0x00117654`) registered via `sceGsSyncVCallback`. | **Medium** | **High** | Verify in M04 that `sceDmaSend` completes synchronously (so `sceDmaSync` returns `0`), `sceGsSyncVCallback` runs every VSync tick in `EeScheduler`, and `*T0_COUNT` (`0x10000000`) increments. |
| **R-06** | **`RXSNDDRV.IRX` IOP Audio Hang** | `mw/sound` sends SIF RPCs to custom `RXSNDDRV.IRX`. If `RXSNDDRV.IRX` blocks waiting for an unemulated SPU2 DMA/IRQ callback inside `IopEmulator`, `sceSifCallRpc` could block the EE thread. | **Medium** | **Medium** | Run `LIBSD.IRX` + `RXSNDDRV.IRX` in `IopEmulator` (all 11 import libraries are already implemented in `iop_emulator.cpp`) AND add a non-blocking HLE RPC service fallback if any `RXSNDDRV` RPC times out. |
| **R-07** | **Indirect Jump / Vtable Miss (`[guest-branch:missing-target]`)** | A C++ virtual call or switch jump targets an address in `.text` not registered in `g_ps2RecompiledFunctionTable`. | **Medium** | **Medium** | Keep `MissingFunctionPolicy::Stop` (`0`) during testing; read the exact `target=0x...` and `vtbl[...]=0x...` from `PS2Runtime::reportMissingFunction()`, add the boundary to `config/slus_21448.toml`, and re-run `ps2xRecomp`. |
